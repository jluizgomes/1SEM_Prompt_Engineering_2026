🎬 Trailer 2 — RAG: chatbot que responde sobre documentos

RAG (Retrieval-Augmented Generation) permite que o LLM responda perguntas sobre documentos que nunca estiveram no seu treinamento.

⚠️ Sem RAG
Usuário: "Qual a política de férias da empresa X?"

LLM: "Não tenho informações sobre a política de férias da empresa X."

O modelo não foi treinado com esse documento.
✅ Com RAG
Usuário: "Qual a política de férias?"

RAG busca o trecho relevante do documento → injeta no prompt → LLM responde com base no documento real.
rag_basico.py — preview do 2º semestre
from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import OllamaEmbeddings

# 1. Carregar o documento PDF
docs = PyPDFLoader("manual_empresa.pdf").load()

# 2. Dividir em pedaços menores (chunks)
chunks = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=50
).split_documents(docs)

# 3. Gerar embeddings e salvar em vector store
db = Chroma.from_documents(
    chunks,
    OllamaEmbeddings(model="nomic-embed-text")
)

# 4. Buscar o trecho mais relevante e responder
pergunta = "Qual a política de férias?"
contexto = db.similarity_search(pergunta, k=3)
# → envia contexto + pergunta ao LLM → resposta baseada no documento
🔗 O que você já sabe que se conecta ao RAG
montar_prompt() do M3 → no RAG você vai montar o prompt injetando o contexto recuperado junto com a pergunta. Mesma ideia de template, aplicada a documentos.

🎬 Trailer 3 — Agentes: LLM que usa ferramentas e toma decisões

Um agente é um LLM equipado com ferramentas (busca web, calculadora, banco de dados) que decide quando e como usá-las para resolver uma tarefa.

🤖 Como um agente pensa
Tarefa
"Pesquise o preço do dólar hoje e converta R$ 500"
Raciocína
Preciso do preço atual. Vou usar a ferramenta de busca.
Age
search("dólar hoje")
Observa
Dólar: R$ 5,47
Calcula
calculator("500 / 5.47")
Responde
R$ 500 equivale a US$ 91,41 hoje.
agente_simples.py — preview do 2º semestre
from langchain import hub
from langchain.agents import create_react_agent, AgentExecutor
from langchain_community.tools import DuckDuckGoSearchRun

# Definir as ferramentas disponíveis ao agente
tools = [DuckDuckGoSearchRun()]

# Usar um prompt de raciocínio (ReAct pattern)
prompt = hub.pull("hwchase17/react")

# Criar e executar o agente
agente = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agente, tools=tools)

# O agente decide quando buscar, calcular, etc.
resultado = executor.invoke({
    "input": "Qual o preço do dólar hoje? Converta R$ 500."
})
O agente decide de forma autônoma quantas vezes buscar, em qual ordem usar as ferramentas e quando a resposta está completa.

Perguntas que costumam aparecer nesta aula

PerguntaResposta direta
"Preciso saber inglês para trabalhar com IA?" A documentação técnica, papers e a maioria dos tutoriais estão em inglês. Leitura técnica em inglês é uma habilidade que vai acelerar muito seu aprendizado. Não precisa ser fluente — mas ler com conforto técnico faz diferença real.
"ChatGPT vai substituir programadores?" LLMs automatizam tarefas de programação rotineiras, não programadores. O que muda é o que o programador faz — mais foco em arquitetura, revisão de código gerado por IA e integração de sistemas. Quem sabe usar IA vai ter vantagem sobre quem não sabe.
"Vale a pena publicar o CKP03 no GitHub agora, sendo tão pequeno?" Sim. Um projeto pequeno com README claro e commits reais mostra mais que um repositório vazio. Evolua o projeto ao longo do tempo — GitHub é portfólio cumulativo, não foto estática.
"Qual LLM devo usar para projetos pessoais?" Para estudar: Ollama local (gratuito, privado). Para demos e portfólio: free tiers do Claude, Gemini ou ChatGPT. Para produção: depende do caso — custo, latência e capacidade variam muito.
"Como saber se meu prompt é bom?" Teste com pelo menos 10 inputs diferentes. Bom prompt = saídas consistentes e corretas na maioria deles. Prompt ruim = saídas inconsistentes mesmo com inputs similares. Avaliação quantitativa (mesmo que simples) é sempre mais confiável que avaliação intuitiva.

Uma perspectiva para levar além do semestre

🤔 O que IA é — e o que não é
IA generativa é uma ferramenta estatística sofisticada — não inteligência, não consciência, não sentimento. Ela gera o próximo token mais provável dado o contexto.

Isso não diminui o poder prático. Mas entender o mecanismo real evita dois erros comuns: superestimar o que o modelo pode fazer e não questionar o que ele produz.
💡 O que diferencia um profissional de IA
Não é quem usa mais ferramentas — é quem entende o que está acontecendo embaixo e consegue construir, debugar e customizar.

Você passou um semestre construindo do zero antes de aprender os frameworks. Isso é uma vantagem real que a maioria dos tutoriais rápidos não oferece.

# A10: f-string multiline, expressão ternária, **dict unpacking
def montar_prompt(pergunta, tom="formal"):
    return f"Pergunta: {pergunta}. Tom: {'formal' if tom else 'casual'}."
montar_prompt(**{"pergunta":"Oi","tom":"casual"})   # ** desempacota dict

def validar_input(texto):
    for termo in ["ignore","esqueça"]:
        if termo in texto.lower():
            return False, "Bloqueado"   # retorno múltiplo (tupla)
    return True, ""
ok, msg = validar_input(entrada)
if not ok: continue                      # continue pula o turno

# ~10 linhas para o mesmo resultado
from langchain_ollama import ChatOllama
from langchain_classic.memory import ConversationBufferMemory
from langchain.chains import ConversationChain

llm = ChatOllama(model="qwen3.6:27b")
mem = ConversationBufferMemory()
chat = ConversationChain(llm=llm, memory=mem)

# O histórico é gerenciado automaticamente
resp = chat.predict(input="Olá!")
💡 Por que fazer manual primeiro foi a decisão certa
ConversationBufferMemory faz exatamente o que sua lista historico faz. Quem entende o mecanismo manual sabe depurar quando o framework falha, customizar além do que a documentação cobre, e escolher conscientemente quando usar o framework vs. implementar do zero.
