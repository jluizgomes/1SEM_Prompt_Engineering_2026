Glossário da Aula 13

Prompt Engineer
Perfil que escreve, testa e otimiza prompts para produtos de IA, cuidando de consistência e qualidade dos outputs. Faixa salarial de referência: R$ 5k–12k/mês. Base já construída nas Aulas 04–07.
AI Application Developer
Perfil que integra LLMs em aplicações usando Python, APIs e frameworks como LangChain, construindo chatbots, pipelines de RAG e interfaces. Faixa salarial de referência: R$ 8k–18k/mês.
ML Engineer
Perfil que treina, avalia e faz deploy de modelos de ML/IA em produção, lidando com infraestrutura, MLOps, performance e escalabilidade. Faixa salarial de referência: R$ 12k–25k/mês.
AI Product Manager
Perfil que define o produto, prioriza features e traduz necessidades de negócio em especificações técnicas para times de IA. Combina base técnica com habilidades de negócio.
Data Engineer com IA
Perfil que constrói pipelines de dados que alimentam sistemas de IA — ingestão, limpeza, embeddings e vector stores, com monitoramento. Faixa salarial de referência: R$ 10k–20k/mês.
MLOps
Conjunto de práticas e ferramentas (como MLflow, Kubeflow) para treinar, versionar, monitorar e colocar modelos de ML em produção de forma confiável — habilidade central do ML Engineer.
Vector store
Banco de dados especializado em armazenar embeddings e buscar por similaridade semântica (ex: ChromaDB, Pinecone, FAISS) — peça central de pipelines de RAG.
Portfólio técnico
Conjunto de projetos reais (como o chatbot do CKP03) documentados e publicados no GitHub, usados por recrutadores para avaliar habilidade prática — considerado mais decisivo que o currículo.

O que está acontecendo no mercado de TI com IA

Perfis de carreira em IA — parte 1

Prompt Engineer / AI Content Specialist
Especialista em Prompts
R$ 5k – 12k/mês
O que faz: escreve, testa e otimiza prompts para produtos de IA. Trabalha com produto, marketing e engenharia para garantir que os outputs sejam consistentes e de qualidade.

Habilidades: domínio de técnicas de prompting · avaliação qualitativa de outputs · escrita clara · noções de UX · ferramentas especializadas de prompt engineering e observability.

Onde trabalha: empresas de produto com IA generativa, agências de marketing digital, consultorias.
AI Application Developer
Desenvolvedor com IA
R$ 8k – 18k/mês
O que faz: integra LLMs em aplicações usando Python, APIs e frameworks como LangChain. Constrói chatbots, pipelines de RAG, automações e interfaces.

Habilidades: Python intermediário · APIs REST · LangChain/LangGraph · ChromaDB/FAISS · Gradio/Streamlit · Git.

Onde trabalha: startups de IA, times de produto de empresas de médio a grande porte, fintechs, healthtechs.
✅ Esses 2 perfis são os mais acessíveis a partir deste semestre
Você já tem base para Prompt Engineer (técnicas de A04 a A07). Com o 2º semestre (LangChain, RAG, interfaces), você terá base para AI Application Developer.

Por que portfólio importa mais que currículo

📄 Currículo — o que você diz que sabe
"Tenho conhecimento em Python e IA" — todo candidato escreve isso.

O recrutador técnico não consegue avaliar o nível real só pelo currículo. Para vagas competitivas, currículo é apenas o filtro inicial.
💻 Portfólio — o que você prova que sabe
"Construí um chatbot especializado em X com Python, Ollama e histórico de conversa" + link do GitHub com README claro.

O recrutador técnico pode ler o código, rodar o projeto e avaliar a qualidade real. Isso diferencia candidatos.
Dado real: em vagas de tecnologia com muitos candidatos, ter projetos no GitHub com commits reais (não só código copiado) aumenta a taxa de chamada para entrevista.
Para estágio: portfólio é ainda mais importante que experiência profissional — porque você ainda não tem experiência, mas pode ter projetos que demonstram capacidade.

+
Extra: screenshot ou GIF — um GIF de 10 segundos mostrando o chatbot funcionando vale mais que qualquer texto no README

NUNCA commite a API key no repositório — use Colab Secrets ou variáveis de ambiente. Credenciais expostas no GitHub são um risco de segurança sério e invalidam o projeto profissionalmente.

Do 1º para o 2º semestre — a progressão

✅ 1º semestre — o que você tem
→ Conceitos de IA, LLMs, tokens
→ Técnicas de prompting (zero/few/CoT/role)
→ Python: funções, while, f-string, dicionários

→ Chatbot com persona, histórico e template
→ Guardrail básico de segurança
→ Noção de OWASP LLM Top 10
🔮 2º semestre — o que você vai adicionar
→ LangChain — abstrai o que você fez manual
→ RAG — chatbot que responde sobre documentos
→ Embeddings — representação semântica de texto
→ Vector stores — ChromaDB, FAISS
→ Agentes — LLM que usa ferramentas
→ Gradio/Streamlit — interfaces para demos
→ LangGraph — fluxos de agentes complexos
🔗 A ponte entre os dois semestres
No 2º semestre, LangChain vai fazer automaticamente o que você fez manualmente: gerenciar histórico, formatar prompts, chamar a API. Quem fez na mão no 1º semestre entende o que o framework abstrai — e isso é uma vantagem enorme ao debugar e customizar.

O que mais importa além do código

🗣️
Comunicação técnica
Saber explicar o que você fez para pessoas não-técnicas. Recrutadores de RH, gerentes de produto e clientes precisam entender o valor do que você construiu.

Praticar: escrever posts no LinkedIn sobre o que aprendeu. Sem jargão desnecessário.
🤝
Trabalho colaborativo
O CKP03 foi em grupo. Projetos reais de empresa são sempre em equipe. Saber usar Git, documentar o código, respeitar padrões e dar feedback construtivo são habilidades tão valiosas quanto o código em si.
🔍
Aprendizado contínuo
IA generativa muda em semanas, não anos. A habilidade mais valiosa não é saber uma tecnologia específica — é saber aprender tecnologias novas rápido.

Praticar: 1 tutorial novo por mês. Documentar o que aprendeu.
💡 O paradoxo do especialista iniciante
Empresas preferem contratar alguém que sabe o que não sabe e aprende rápido do que alguém que acha que sabe tudo. Dizer "não sei, mas consigo descobrir" em uma entrevista é frequentemente a resposta mais valorizada.

O que não foi ensinado — e por quê

Transparência sobre o escopo: há muito mais em IA do que coube neste semestre. Isso é intencional.

TópicoPor que não foi ensinado agoraQuando vai aparecer
Fine-tuning de modelos Requer ML avançado e infra de GPU — fora do escopo de 1º semestre 3º ou 4º semestre de CC
Redes neurais e backpropagation Fundamentos de álgebra linear e cálculo necessários antes Disciplinas de ML (3º semestre)
Deploy em produção (cloud, Docker) Requer infraestrutura e DevOps — disciplinas específicas 2º ou 3º semestre
LangGraph e agentes complexos Requer base de LangChain e Python intermediário — build-up 2º semestre
Visão computacional e multimodalidade Requer base de CNNs e processamento de imagem 3º ou 4º semestre
✅ O que foi priorizado — e por quê faz sentido
O 1º semestre focou nos fundamentos que não mudam rapidamente: como LLMs funcionam conceitualmente, como escrever bons prompts, e como integrar LLMs em Python de forma legível e segura. Essa base é o que permite aprender LangChain, RAG e agentes mais rápido no 2º semestre.

Quem contrata — empresas com IA no Brasil em 2026

Fintechs
Automação de atendimento + análise
Chatbots de atendimento, análise de documentos, detecção de fraude com LLMs. Perfis mais contratados: AI Developer e Data Engineer com IA. Vagas de estágio frequentes para quem tem Python e noções de LLM.
Healthtechs
Triagem, suporte clínico e documentação
Uso de LLMs para triagem de sintomas, geração de resumos de prontuários e chatbots de agendamento. Alto crescimento de vagas, mas exige atenção especial a ética e LGPD — o que você já estudou.
Consultorias
IA como serviço para clientes corporativos
Construção de soluções de IA para clientes de vários setores. Buscam profissionais que saibam desenvolver, mas também explicar e vender a solução. Comunicação técnica é diferencial.
Startups de IA — cenário crescente
Constroem produtos com LLMs do zero
Startups em fase seed e early-stage contratam desenvolvedores com Python + LangChain + IA generativa. Menor salário inicial, maior velocidade de aprendizado.

Exercício — Aula 13
Carta para o eu de 5 anos ★

Individual · 15 minutos · Papel ou editor de texto

Escreva 5 linhas respondendo as perguntas abaixo. Não existe resposta certa — o objetivo é você se conectar com o porquê de estar neste curso:

  1. Qual carreira você imagina ter em 5 anos? (pode ser vaga — "trabalhar com tecnologia", "criar um produto", "ter minha empresa")
  2. Como IA estaria presente no seu trabalho daqui a 5 anos? O que você usaria de IA no dia a dia dessa carreira imaginada?
  3. O que você construiu neste semestre que você não sabia que seria capaz de construir quando entrou?
  4. O que você vai fazer diferente no próximo semestre para avançar mais rápido?
  5. Uma habilidade que você quer dominar até o final do curso de CC.
📢 Compartilhamento voluntário
Ao final dos 15 min, quem quiser compartilha 1 das respostas com a turma. Sem obrigação — mas escutar o caminho dos outros costuma abrir perspectivas novas.
💡 Por que este exercício vale o tempo: pesquisas em educação profissional mostram que estudantes com clareza de propósito têm desempenho e conclusão de curso significativamente maiores. 5 linhas agora podem economizar semestres de dúvida depois.
