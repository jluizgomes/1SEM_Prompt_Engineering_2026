Glossário da Aula 11

chamar_llm()
Função da Aula 08 que envia um único prompt à API e retorna o texto da resposta. Responsabilidade única: comunicar com o modelo — não guarda histórico nem monta templates.
iniciar_chat()
Função da Aula 09 que roda um loop while True, acumulando o histórico da conversa e reenviando-o a cada turno. Responsabilidade única: orquestrar a conversa com memória.
montar_prompt()
Função da Aula 10 que usa um template com f-string para receber variáveis e retornar um prompt formatado. Responsabilidade única: construir o texto do prompt.
Histórico (messages)
Lista que acumula todas as trocas entre usuário e modelo dentro de uma sessão de chat, reenviada por inteiro a cada novo turno para que o modelo mantenha contexto.
Persona
Perfil definido no system prompt que dá ao chatbot uma especialidade e um tom consistente — requisito obrigatório do chatbot especializado do CKP03.
Responsabilidade única
Princípio de design em que cada função faz exatamente uma coisa — chamar_llm(), iniciar_chat() e montar_prompt() não se sobrepõem, o que facilita testar e integrar cada peça.
Integração
Combinar as 3 funções isoladas das Aulas 08–10 num único fluxo: montar_prompt() formata → entra no histórico → iniciar_chat() envia e guarda a resposta.
CKP03
Checkpoint opcional que substitui a menor nota entre CKP01 e CKP02 se for maior. Entrega: notebook Colab com chatbot especializado (persona, template de prompt, histórico e condição de saída) testado com 5+ turnos.

Aula 09 — iniciar_chat(system="")

Aula 10 — montar_prompt(pergunta, ...)

chamar_llm() foi usada nas Aulas 08, 09 e 10 para chamadas isoladas — no chatbot integrado, a chamada à API fica dentro de iniciar_chat() diretamente.

CKP03 — Exemplos de personas bem escritas

A persona é o elemento que mais diferencia chatbots mediocres de chatbots eficientes. Veja a diferença:

❌ Persona genérica — não passe disso
"Você é um especialista em finanças. Ajude o usuário."
✅ Persona completa — alvo do CKP03
"Você é a Vera, consultora de finanças pessoais para jovens de 18 a 25 anos que estão começando a trabalhar. Sua linguagem é descontraída mas precisa. Você explica conceitos com analogias do dia a dia. IMPORTANTE: você NÃO recomenda fundos, ações ou produtos financeiros específicos — você educa sobre os princípios. Sempre termine com uma pergunta que incentive o usuário a refletir sobre sua situação."
✅ Outro exemplo — tutor de programação
"Você é Lucas, tutor de Python para iniciantes absolutos (nunca programaram). Você é paciente, encorajador e celebra cada progresso. Você NUNCA dá a resposta pronta — você faz perguntas para guiar o aluno a descobrir sozinho. Quando o aluno erra, você parabeniza pela tentativa e sugere o próximo passo."

# Versão estendida do chatbot — extras opcionais
def iniciar_chat(especialidade, persona, max_turnos=20):
    historico = [{"role": "system", "content": persona}]
    turno = 0                     # extra 1: contador de turnos
    print(f"🤖 {especialidade} — máx {max_turnos} turnos\n")

    while True:
        if turno >= max_turnos:   # extra 2: limite automático
            print("Limite de turnos atingido.")
            break

        entrada = input("Você: ")
        if entrada.lower() == "sair": break

        prompt_formatado = montar_prompt(entrada, especialidade)
        historico.append({"role": "user", "content": prompt_formatado})

        # extra 3: janela deslizante — mantém system + últimos 10
        if len(historico) > 12:
            historico = historico[:1] + historico[-10:]

        resp     = _client.chat(model=MODELO, messages=historico)
        resposta = resp["message"]["content"]
        historico.append({"role": "assistant", "content": resposta})

        turno += 1
        print(f"[turno {turno} · {len(historico)} msgs] {resposta}\n")

Erros comuns na integração das 3 peças

ErroCausaComo corrigir
Chatbot ignora o domínio e responde sobre qualquer coisa System prompt não está na lista historico — foi passado de outra forma ou omitido Confirmar que historico[0]["role"] == "system" antes de iniciar o loop
Modelo não usa o template — responde como se pergunta fosse texto puro montar_prompt() não está sendo chamada — entrada vai direto para o append historico.append({"role":"user","content":prompt_formatado}) — não entrada
Cada resposta parece uma conversa nova — sem contexto Esqueceu de adicionar o role "assistant" após receber a resposta Confirmar que há 2 appends por turno: um "user" antes, um "assistant" depois da chamada
Loop não encerra com "sair" Comparação case-sensitive (== "sair" sem .lower()) entrada.lower() == "sair"
KeyError: 'message' A API retornou um erro (credencial inválida, modelo indisponível) Verificar OLLAMA_API_KEY em Colab Secrets; testar com uma chamada simples antes

Anthropic — Context Engineering (2025)
Anthropic popularizou o termo "context engineering" em 2025 para descrever exatamente o que você fez: gerenciar deliberadamente o que vai na janela de contexto (system prompt + histórico + template). O M3 inteiro é context engineering aplicado.
LangChain — ConversationChain
A classe ConversationChain do LangChain faz exatamente o que iniciar_chat() faz — gerencia o histórico e injeta no prompt automaticamente. Você aprendeu o conceito antes de aprender o framework.
Plataformas de atendimento ao cliente
Ferramentas de atendimento ao cliente usam exatamente o padrão system prompt de persona + histórico de sessão + template por tipo de solicitação. A diferença é que elas têm integração com CRM e banco de dados — não apenas o loop de conversa.

Perguntas frequentes — Aula 11 e CKP03

PerguntaResposta
"Posso usar a função chamar_llm() da Aula 08 dentro do loop?"Funciona, mas não é o padrão. chamar_llm() monta uma lista nova a cada chamada — descarta o histórico. Para ter memória, a chamada ao _client.chat() deve receber a lista historico acumulada. No chatbot integrado, fazemos isso diretamente.
"O grupo pode mudar o domínio depois de escolher?"Sim, até a entrega. Mas escolher logo permite praticar durante a aula e tirar dúvidas com o professor ainda hoje.
"O que acontece com o histórico se eu re-executar a Célula 3?"A lista é recriada do zero (historico = [{"role":"system",...}]). Toda conversa anterior é perdida. Para preservar, salve em JSON antes de re-executar.
"Posso adicionar mais de um system prompt?"Tecnicamente sim, mas a API trata apenas o primeiro (ou funde os dois, dependendo do modelo). O padrão correto é um único system prompt bem escrito com todas as instruções.
"O CKP03 precisa ter interface gráfica?"Não — a interface do CKP03 é o terminal do Colab mesmo. Interface com Gradio/Streamlit é tema do 2º semestre. O foco agora é a lógica do chatbot.

def chamar_llm(prompt, system=""):                # parâmetro com padrão

# ── A09: while True, break, .lower(), role assistant ──
historico = []                                  # lista crescente
while True:                                     # loop indefinido
    entrada = input("Você: ")
    if entrada.lower() == "sair": break          # saída explícita
    historico.append({"role": "user",      "content": entrada})
    historico.append({"role": "assistant", "content": resposta})

# ── A10: f-string multiline, expressão ternária, **dict
def montar_prompt(pergunta, tom="formal", max_palavras=80):
    return f"""
    {pergunta}
    Tom: {tom}. {'Seja breve.' if max_palavras < 50 else ''}
    """                                         # f-string com ternário

cfg = {"pergunta": "Oi", "tom": "casual"}
montar_prompt(**cfg)                              # ** desempacotamento

# ── A11: integração — as 3 peças juntas ───────────────
def iniciar_chat(especialidade, persona):
    historico = [{"role": "system", "content": persona}]
    while True:
        entrada = input("Você: ")
        if entrada.lower() == "sair": break
        pf = montar_prompt(entrada, especialidade)    # A10
        historico.append({"role": "user",      "content": pf})   # A09
        r = _client.chat(model=MODELO, messages=historico)     # A08
        historico.append({"role": "assistant", "content": r["message"]["content"]})

# ── CÉLULA 2: Template de prompt (peça da Aula 10) ───────
def montar_prompt(pergunta, especialidade, estilo="direto e didático"):
    """Formata a pergunta do usuário com contexto da especialidade."""
    return f"""
Pergunta sobre {especialidade}: {pergunta}
Estilo de resposta: {estilo}.
Use exemplos concretos quando útil. Máximo 3 parágrafos.
"""

# Testar o template ANTES de integrar ao chatbot
teste = montar_prompt("o que é marinada?", "culinária brasileira")
print(teste)
# ← confirmar que o template ficou certo ANTES de chamar o LLM

# ── CÉLULA 3: Chatbot integrado — as 3 peças do M3 juntas
def iniciar_chat(especialidade, persona):
    """
    Chatbot especializado com histórico e template de prompt.
    Integra: montar_prompt (A10) + histórico messages (A09) + Ollama API (A08)
    """
    # Inicializa o histórico com a persona (system prompt) — A07
    historico = [{
        "role": "system",
        "content": persona
    }]

    print(f"\n🤖 Chatbot de {especialidade} iniciado.")
    print("   Digite 'sair' para encerrar.\n")

    # Loop de conversa — A09
    while True:

        # Passo 1: ler entrada do usuário
        entrada = input("Você: ")
        if entrada.lower() == "sair":
            print("Encerrando. Até logo!")
            break

        # Passo 2: usar template para formatar a pergunta — A10
        prompt_formatado = montar_prompt(entrada, especialidade)

        # Passo 3: adicionar ao histórico — A09
        historico.append({"role": "user", "content": prompt_formatado})

        # Passo 4: chamar a API com o histórico completo — A08
        resp = _client.chat(model=MODELO, messages=historico)
        resposta = resp["message"]["content"]

        # Passo 5: guardar a resposta no histórico — A09
        historico.append({"role": "assistant", "content": resposta})

        # Passo 6: exibir
        print(f"Assistente: {resposta}\n")

# ── Executar com domínio de culinária ────────────────────
iniciar_chat(
    especialidade="culinária brasileira",
    persona=(
        "Você é um chef especializado em culinária brasileira. "
        "Explique receitas com linguagem acessível, mencione variações "
        "regionais quando relevante e sugira substituições práticas."
    )
)

Lab — Aula 11 · CKP03
Construir e testar o chatbot especializado ★★★

Grupo 3–4 · 35 minutos · Google Colab

  1. Forme o grupo do CKP03 — 3 a 4 integrantes. Escolha agora o domínio do chatbot (veja sugestões abaixo). Cada grupo deve ter um domínio diferente.
  2. Complete as 7 lacunas na Célula 3 — roles system/user/assistant, True, "sair", break, chamada a montar_prompt(), e a chamada final com seu domínio e persona.
  3. Adapte o template — modifique a Célula 2 para a especialidade do seu grupo. Adicione pelo menos 1 parâmetro a mais além de pergunta e especialidade.
  4. Escreva a persona — no system prompt, inclua: nome do assistente, área de especialização, público-alvo, tom de voz e 1 restrição de escopo (o que o chatbot NÃO responde).
  5. Teste com 5 turnos — no turno 4 ou 5, pergunte algo que dependa de uma resposta anterior para testar o histórico.
💡 Sugestões de domínio
Culinária brasileira · Finanças pessoais · Saúde e bem-estar · Programação Python · Games e e-sports · Literatura e livros · Viagens no Brasil · Direito do consumidor · Inglês para brasileiros · Esportes
✅ Gabarito das lacunas
Lacuna 1: "system", persona
Lacuna 2: True
Lacuna 3: "sair" (e break)
Lacuna 4: montar_prompt(entrada, especialidade)
Lacuna 5: "user", prompt_formatado
Lacuna 6: "assistant", resposta
Lacuna 7: seu domínio e persona
💡 Persona bem feita = chatbot melhor. Compare: persona ruim: "Você é especialista em finanças." — Persona boa: "Você é a Vera, consultora de finanças pessoais para jovens de 18–25 anos.
