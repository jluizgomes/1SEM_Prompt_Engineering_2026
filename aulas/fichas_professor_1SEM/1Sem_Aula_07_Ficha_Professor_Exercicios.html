ATIVIDADE 01

Criar 3 Personas para o Domínio do CKP02

Individual ou dupla · 20 minutos · ★ ★ ★

🎯 Objetivo Pedagógico

Construir e comparar 3 system prompts de persona para o mesmo domínio — a base direta dos 2 prompts 'role' exigidos no CKP02.

🧩 Conceitos Trabalhados

🐍 Dicionário de strings multilinha🐍 Loop sobre dict.items()🤖 Role prompting🤖 System prompt vs. user prompt🤖 Parâmetro temperature

⚙️ Preparação Prévia

Setup padrão (ollama + Colab Secrets) — já visto nas aulas anteriores.

📋 Passo a Passo

1Escolher o domínio do CKP02 do grupo e escrever 3 personas — Completar as 3 lacunas com personas diferentes, coerentes com o domínio (saúde, educação, varejo, etc.).
2Executar e comparar as 3 respostas lado a lado — Mesma pergunta, 3 personas — observar as diferenças.
3Analisar as diferenças — Qual persona deu a resposta mais útil? O vocabulário mudou? O formato? O que cada uma priorizou?
4Diferencial — ajustar temperature — Testar 0.2, 0.7 e 1.0 para cada persona. Qual combinação persona + temperature funcionou melhor?

✅ Gabarito

O que faz um bom system prompt de persona: quem é, o que sabe, como fala, o que nunca faz, para quem fala. 4-6 linhas bem escritas valem mais que 20 linhas vagas.

# -- Complete as 3 personas ----------------------------------
personas = {

    "persona_1": """
👉 LACUNA 1: Escreva o system prompt para uma persona de sua escolha
    Inclua: quem e, qual especialidade, tom, restricoes, publico-alvo.
    """,

    "persona_2": """
👉 LACUNA 2: Escreva uma segunda persona DIFERENTE da primeira
    Mesma area de dominio do CKP02 do seu grupo, persona diferente.
    """,

    "persona_3": """
👉 LACUNA 3: Escreva uma terceira persona -- pode ser critica ou cetica
    Ex: auditora, jornalista investigativa, advogada do diabo...
    """,
}

# Pergunta teste -- pode trocar pela do seu dominio
pergunta = "Quais sao os principais beneficios e riscos de usar IA nesta area?"

# Loop -- nao modifique
for nome, system in personas.items():
    resp = client.chat(
        model="qwen3.6:27b",
        messages=[
            {"role": "system", "content": system},
            {"role": "user",   "content": pergunta}
        ],
        options={"temperature": 0.7, "num_predict": 400}
    )
    print(f"\n{'='*50}\n{nome.upper()}\n{resp['message']['content']}")

⚠️ Erros Comuns / Pontos de Atenção

Personas vagas demais ('Você é especialista em finanças') não geram diferenciação suficiente — comparar com um exemplo bom ao vivo: 'Você é a Vera, consultora de finanças pessoais para jovens de 18-25 anos...'
