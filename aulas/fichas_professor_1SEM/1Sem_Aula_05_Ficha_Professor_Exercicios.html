ATIVIDADE 01

Construir Exemplos Representativos

Individual ou dupla · 25 minutos · ★ ★ ★

🎯 Objetivo Pedagógico

Construir um classificador few-shot de urgência de tickets, entendendo que a qualidade dos exemplos — não a quantidade de instrução — é o que determina a precisão do modelo.

🧩 Conceitos Trabalhados

🐍 f-string multilinha🐍 Formatação de prompt com múltiplos exemplos🤖 Few-shot prompting🤖 Exemplos representativos vs. óbvios

⚙️ Preparação Prévia

Setup padrão (ollama + Colab Secrets).

📋 Passo a Passo

1Preencher as 4 lacunas com tickets reais — Um exemplo de cada categoria (CRÍTICO, ALTO, MÉDIO, BAIXO) — pensar em situações já vividas como usuário de algum serviço.
2Executar e conferir a classificação do ticket de teste — Deve classificar corretamente como CRÍTICO.
3Testar com outros tickets — Trocar o ticket final por 2 novos casos e ver se a classificação permanece consistente.
4Desafio: revisar exemplos se o modelo errar — São representativos o suficiente? Ajustar e rodar de novo.

✅ Gabarito

Exemplos de referência:
CRÍTICO: "Banco de dados corrompido, dados de clientes perdidos"
ALTO: "Módulo de checkout com erro para 30% dos usuários"
MÉDIO: "Relatório de vendas não carrega para o usuário X"
BAIXO: "Mudar a cor do botão de salvar para azul"

Código que os alunos executarão no Google Colab. Narre cada bloco explicando o propósito de cada trecho.

import ollama
from google.colab import userdata
Aula05_lab.py · Google Colab
client = ollama.Client(
    host="https://api.ollama.com",
    headers={"Authorization": f"Bearer {userdata.get("OLLAMA_API_KEY")}"}
)

# -- TAREFA: classificador de URGENCIA de tickets de suporte --
# Categorias: CRITICO, ALTO, MEDIO, BAIXO

few_shot = f"""
Classifique a urgencia do ticket: CRITICO, ALTO, MEDIO ou BAIXO.

👉 LACUNA 1: escreva um exemplo de ticket CRITICO
Ticket: ___ -> CRITICO

👉 LACUNA 2: escreva um exemplo de ticket ALTO
Ticket: ___ -> ALTO

👉 LACUNA 3: escreva um exemplo de ticket MEDIO
Ticket: ___ -> MEDIO

👉 LACUNA 4: escreva um exemplo de ticket BAIXO
Ticket: ___ -> BAIXO

Ticket: "O sistema de pagamento esta fora do ar para todos os clientes."
"""

# Chamada e resultado -- nao modifique
resp = client.chat(
    model="qwen3.6:27b",
    messages=[{"role": "user", "content": few_shot}]
)
print(f"Resultado: {resp["message"]["content"]}")

⚠️ Erros Comuns / Pontos de Atenção

Exemplos óbvios demais ('sistema caiu' → CRÍTICO) fazem o modelo confundir casos intermediários — reforçar: os exemplos precisam ser realistas, não caricatos.

💬 Sugestão de Discussão

O segredo dos bons exemplos: usar textos que uma pessoa real escreveria num ticket — nem óbvios demais, nem vagos demais. Essa técnica volta reforçada na Aula 06 com Chain-of-Thought.
