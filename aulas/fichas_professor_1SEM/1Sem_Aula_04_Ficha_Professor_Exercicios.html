ATIVIDADE 01

Complete, Rode e Itere

Individual · 20 minutos · Google Colab · ★ ★ ★

🎯 Objetivo Pedagógico

Enviar um prompt a um LLM via código Python e receber a resposta — primeira vez que o aluno controla o modelo programaticamente, sem interface gráfica.

🧩 Conceitos Trabalhados

🐍 Variáveis🐍 String multilinha (triple-quote)🐍 Dicionário como argumento🤖 Anatomia do prompt (instrução+contexto+input+formato)🤖 Parâmetros: modelo, num_predict

⚙️ Preparação Prévia

Setup padrão (ollama + Colab Secrets com OLLAMA_API_KEY) já incluído na Célula 1.

📋 Passo a Passo

1Completar as 3 lacunas — Modelo, prompt (com os 4 componentes) e max_tokens.
2Rodar e observar a resposta — Shift+Enter — a resposta aparece logo abaixo da célula.
3Trocar só o prompt e comparar — Mesmo código, texto diferente — observar como a resposta muda.
4Desafio: trocar o modelo e o max_tokens — qwen3.6:27b → gemma4:9b com o mesmo prompt. Depois testar valores baixos e altos de max_tokens.

✅ Gabarito

Lacuna 3: um número como 150 ou 300 — num_predict é o parâmetro do Ollama equivalente a "max_tokens". Valor baixo corta a resposta no meio; valor alto permite respostas mais longas (e mais lentas).

Sugestão para a Lacuna 2: "Você é um especialista em [área]. Explique [conceito] para alguém que nunca estudou [área]. Use 1 exemplo do cotidiano. Responda em no máximo 3 parágrafos."
