# Aula 04 — Anatomia do Prompt: Primeiro Código Python

Primeira aula com código usando a API Ollama diretamente.

## Como executar

```bash
# 1. Instale as dependências
pip install -r requirements.txt

# 2. Configure o arquivo .env
cp .env.example .env
# Edite .env com sua chave de API

# 3. Execute
python main.py
```

## Saída esperada

O script demonstra os 4 componentes de um prompt bem estruturado: contexto, instrução, entrada e formato.

## Requisitos

- Python 3.9+
- Chave de API Ollama (gratuita em ollama.com)
