# Aula 01 — O que é IA: Da ficção à realidade

Projeto demonstrativo dos conceitos de Inteligência Artificial, Machine Learning e Deep Learning.

## Como executar

```bash
python main.py
```

## Saída esperada

O script classifica exemplos de texto em categorias usando detecção de palavras-chave, demonstrando a evolução de IA → ML → Deep Learning.

## Requisitos

- Python 3.9+
- Nenhuma dependência externa
