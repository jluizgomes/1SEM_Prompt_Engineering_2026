# Aula 03 — Ética, Viés, LGPD e Responsabilidade

Projeto demonstrativo de auditoria ética de prompts e validação de dados pessoais.

## Como executar

```bash
python main.py
```

## Saída esperada

O script valida prompts contra diretrizes éticas, verifica dados pessoais (LGPD) e demonstra conceitos de viés algorítmico.

## Requisitos

- Python 3.9+
- Nenhuma dependência externa
