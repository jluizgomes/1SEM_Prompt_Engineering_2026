# Aula 02 — Tokens, Contexto e Temperatura

Projeto demonstrativo dos conceitos de tokens, janela de contexto e temperatura em LLMs.

## Como executar

```bash
python main.py
```

## Saída esperada

O script conta palavras/tokens em textos, demonstra o conceito de contexto e mostra efeitos da temperatura.

## Requisitos

- Python 3.9+
- Nenhuma dependência externa
